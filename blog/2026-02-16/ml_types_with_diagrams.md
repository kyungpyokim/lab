# 📊 머신러닝 문제 유형 (그림 포함 학습용)

------------------------------------------------------------------------

# 🧠 머신러닝 문제 큰 구조

``` mermaid
flowchart TD
    A[머신러닝 문제] --> B{정답 라벨 존재?}
    B -->|YES| C{출력이 숫자인가?}
    C -->|YES| D[회귀 Regression]
    C -->|NO| E[분류 Classification]
    B -->|NO| F[군집 Clustering]
```

------------------------------------------------------------------------

# 📌 1️⃣ 회귀 (Regression)

## 🎯 개념

👉 **숫자를 예측하는 문제**

------------------------------------------------------------------------

## 📉 구조 그림

``` mermaid
flowchart LR
    X[고객 정보] --> Y[회귀 모델]
    Y --> Z[숫자 결과<br/>예: 3.2억 / 250GB]
```

------------------------------------------------------------------------

## 💡 예시

-   집값 예측
-   매출 예측
-   사용량 예측
-   수요 예측

------------------------------------------------------------------------

## 📊 대표 모델

-   Linear Regression
-   Ridge / Lasso
-   XGBoost Regressor
-   LightGBM Regressor

------------------------------------------------------------------------

## 📏 평가 지표

  지표   의미
  ------ ----------------
  MAE    평균 절대 오차
  RMSE   큰 오차에 민감
  R²     설명력

------------------------------------------------------------------------

# 📌 2️⃣ 분류 (Classification)

## 🎯 개념

👉 **카테고리를 예측하는 문제**

------------------------------------------------------------------------

## 📉 구조 그림

``` mermaid
flowchart LR
    X[고객 정보] --> Y[분류 모델]
    Y --> Z[이탈 / 유지<br/>스팸 / 정상]
```

------------------------------------------------------------------------

## 💡 예시

-   고객 이탈 예측
-   사기 거래 탐지
-   스팸 메일 분류
-   질병 진단

------------------------------------------------------------------------

## 📊 대표 모델

-   Logistic Regression
-   RandomForest
-   XGBoost
-   LightGBM

------------------------------------------------------------------------

## 📏 평가 지표

  지표        의미
  ----------- -------------------------
  Accuracy    전체 정확도
  Precision   맞춘 양성 비율
  Recall      놓치지 않은 양성
  F1          Precision + Recall 균형
  ROC-AUC     확률 예측 성능

------------------------------------------------------------------------

# 📌 3️⃣ 군집 (Clustering)

## 🎯 개념

👉 **비슷한 데이터끼리 자동 그룹화**

------------------------------------------------------------------------

## 📉 구조 그림

``` mermaid
flowchart LR
    X[고객 데이터] --> Y[군집 모델]
    Y --> Z[Cluster 1 / 2 / 3]
```

------------------------------------------------------------------------

## 💡 예시

-   고객 세그먼트 분석
-   사용자 행동 그룹
-   이상치 탐지

------------------------------------------------------------------------

## 📊 대표 모델

-   K-Means
-   DBSCAN
-   Hierarchical Clustering
-   Gaussian Mixture Model

------------------------------------------------------------------------

# 📌 전체 비교

  구분   정답 라벨   출력   예시
  ------ ----------- ------ ---------------
  회귀   있음        숫자   매출
  분류   있음        라벨   이탈
  군집   없음        그룹   고객 세그먼트

------------------------------------------------------------------------

# ⭐ 한 줄 요약

``` mermaid
flowchart LR
    A[숫자 예측] --> B[회귀]
    C[라벨 예측] --> D[분류]
    E[패턴 발견] --> F[군집]
```

------------------------------------------------------------------------

# 🚀 실무 적용 예시 (Churn 프로젝트)

``` mermaid
flowchart TD
    A[고객 데이터] --> B[군집]
    B --> C[고객 세그먼트 발견]
    C --> D[분류 모델 학습]
    D --> E[이탈 예측]
    E --> F[마케팅 액션]
```
