📊 머신러닝 문제 유형 정리 (회귀 / 분류 / 군집)

February 16, 2026 · 2 min read

📌 1. 회귀 (Regression)​

✅ 정의​

연속적인 숫자(실수값)를 예측하는 문제

✅ 예시​

  • 집값 예측 → 3.8억\
  • 매출 예측 → 1240만원\
  • 온도 예측 → 23.4도\
  • 고객 사용량 예측 → 320GB

✅ 출력 형태​

y = 실수값

✅ 대표 모델​

  • Linear Regression
  • Ridge / Lasso
  • RandomForest Regressor
  • XGBoost Regressor
  • LightGBM Regressor
  • Neural Network Regressor

✅ 대표 평가 지표​

지표 의미

MAE 평균 절대 오차 RMSE 큰 오차에 더 민감 R² 설명력 (1에 가까울수록 좋음)

📌 2. 분류 (Classification)​

✅ 정의​

정해진 카테고리(라벨) 중 하나를 예측하는 문제

✅ 예시​

  • Churn → 이탈 / 유지\
  • 스팸 → 스팸 / 정상\
  • 사기 거래 → Yes / No\
  • 고객 등급 → Bronze / Silver / Gold

✅ 출력 형태​

✔ 클래스​

0 / 1 A / B / C

✔ 확률​

P(Churn) = 0.73

✅ 대표 모델​

  • Logistic Regression
  • SVM
  • Naive Bayes
  • RandomForest Classifier
  • XGBoost Classifier
  • LightGBM Classifier
  • Neural Network Classifier

✅ 대표 평가 지표​

지표 의미

Accuracy 전체 중 맞춘 비율 Precision 양성 예측 중 정답 비율 Recall 실제 양성 중 검출 비율 F1 Score Precision / Recall 균형 ROC-AUC 분류 확률 성능

📌 3. 군집 (Clustering)​

✅ 정의​

정답 라벨 없이 비슷한 데이터끼리 자동 그룹화

✅ 예시​

  • 고객 세그먼트 분류\
  • 사용자 행동 패턴 그룹화\
  • 이상치 탐지 전처리

✅ 출력 형태​

Cluster ID = 0,1,2,3...

✅ 대표 모델​

  • K-Means
  • Hierarchical Clustering
  • DBSCAN / HDBSCAN
  • Gaussian Mixture Model (GMM)

📌 전체 비교 요약​

구분 정답 라벨 목표 출력 예시

회귀 있음 숫자 예측 실수 매출, 가격 분류 있음 범주 예측 라벨 이탈, 스팸 군집 없음 그룹 발견 Cluster ID 고객 세그먼트

📌 한 줄 정리​

숫자 맞추면 → 회귀 라벨 맞추면 → 분류 패턴 찾으면 → 군집
